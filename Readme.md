# Rosa de Sangue
## Crônicas de uma Coroa Partida

RPG narrativo medieval e político.

### Ambientação
Ano de 1470.
Inspiração em Requiem of the Rose King.

### Personagem do jogador
Kazuki von Bismarck.

O jogador controla exclusivamente Kazuki.
A inteligência artificial controla Richard Plantagenet III e os demais NPCs.

### Tecnologias
- HTML
- CSS
- JavaScript
- Cloudflare Pages
- Gemini API

### Idioma
Português brasileiro.
